# This Organization Has Moved

To improve community engagement around BabySea open-source projects, the organization has moved from the `babysea-ai` organization to the `babysea-community` organization.

Please use the new organization location:

[https://github.com/babysea-community](https://github.com/babysea-community)

The new organization is the canonical home for source code, issues, pull requests, releases, security updates, and documentation. This old `babysea-ai` organization is kept only as a pointer so existing links, bookmarks, package metadata, and deploy buttons do not lead to a dead end.

If you reached this page from an old link, please update your bookmark or documentation reference to the corresponding `babysea-community` repository URL.

Thank you for building with BabySea and helping keep the open-source community easier to find, use, and contribute to.
